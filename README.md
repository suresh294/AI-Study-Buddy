# AI Study Buddy — Project Outline

This repository currently contains a project outline only; it does not yet include runnable frontend or backend source code. The features below describe the intended scope, not implemented functionality.

## Planned Features

- Explain study topics at different difficulty levels.
- Generate notes and summaries.
- Create quizzes and flashcards.
- Suggest study plans based on learner progress.

## Proposed Technology Stack

- Frontend: React
- Backend: Python with FastAPI
- Database: MongoDB
- AI: an LLM integration, to be selected and configured during implementation

## Current Status

**Status: Not implemented in this repository yet.** There is no verified deployment, dependency manifest, or setup command at present.

Before this project can be presented as a completed portfolio project, it needs an implemented MVP, setup instructions, tests, and a verified deployment or demo recording.
